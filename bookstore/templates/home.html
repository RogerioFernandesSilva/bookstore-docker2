📚 Bookstore API

API REST de uma livraria (produtos, categorias e pedidos) feita com Django e Django REST Framework.

Rotas

  • /bookstore/v1/product/ — produtos
  • /bookstore/v1/category/ — categorias
  • /bookstore/v1/order/ — pedidos
  • POST /api-token-auth/ — obtém o token (username e password)
  • /admin/ — painel administrativo
  • /hello/ — página de teste do deploy

Autenticação

As rotas /bookstore/... exigem login. Sem credencial a API responde 401. No navegador, informe usuário e senha quando for solicitado; em clientes HTTP, use o cabeçalho Authorization: Token SEU_TOKEN.

Código e documentação: github.com/RogerioFernandesSilva/bookstore-docker2
